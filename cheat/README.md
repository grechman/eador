# Чит-пак для теста новой версии

Оверлей данных. Новая партия, сложность «Начинающий».
Откат: `git reset --hard release-v1-stable` + `cp .grechman/backup-v1-stable/var/difficulty.var var/`.

## Что даёт
- Старт: 1 000 000 золота, 100 000 кристаллов.
- Ополченец = 400 000 опыта (быстрый 30 уровень героям).
- Все постройки по 1 золоту, без ресурсов.
- **Выдача 6 свитков найма - через ритуал.** Построй Библиотеку (1 ход) - она
  открывает ритуал **«Сотворение»**. Скастуй его (бесплатно, кулдаун 1 ход) -
  и все 6 свитков (Игла смерти, Вечное царство, Оракул, Умертвие, Прародитель,
  Крысс) падают в сокровищницу. Это детерминированно, без рандома.
- Заклинания: в пуле выпадения оставлены только 7 новых. Падают из кладов
  особых мест (Древний склеп, Древние руины и т.п.) как свитки для изучения.

## Как быстро всё проверить
1. Новая игра, Начинающий.
2. Построй Библиотеку → скастуй «Сотворение» → забери 6 свитков.
3. Построй гейты найма (Капитолий - Лич/Оракул/Умертвие; Кристальные столпы -
   Повелитель; Великая пирамида - Прародитель; Великий алтарь - Крысс), нанимай.
4. Заклинания тестируй Оракулом (он их кастует; урон масштабируется от силы мага).

## Включить / Выключить
Включить: `cp cheat/var/*.var var/`.
Выключить: `git reset --hard release-v1-stable` (+ difficulty.var из backup-v1-stable).
