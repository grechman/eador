# Чит-пак для теста новой версии

Оверлей данных. Новая партия на сложности «Начинающий».
Откат: `git reset --hard release-v1-stable`, затем
`cp .grechman/backup-v1-stable/var/difficulty.var var/`.

## Что даёт
- Старт: 1 000 000 золота, 100 000 кристаллов.
- Ополченец = 400 000 опыта. Каждый тайник стерегут 2 ополченца = герой 30 ур. за бой.
- Все постройки по 1 золоту (гейты найма строишь мгновенно).
- Новых особых мест НЕ добавляем (это роняло игру). Вместо этого переделаны два
  частых ванильных места, они появляются с 1 уровня почти в каждой провинции:
  - **Древний склеп** - стерегут 2 ополченца. Даёт Иглу смерти, Вечное царство,
    Оракула + свитки новых заклинаний (через его лут-способность).
  - **Древние руины** - 2 ополченца. Даёт Умертвие, Прародителя, Крысса + свитки
    заклинаний.
  - В пуле выпадения заклинаний оставлены ТОЛЬКО 7 новых, так что падают лишь они.

## Включить
Скопировать `cheat/var/*.var` в `var/` игры с заменой.

## Выключить
`git reset --hard release-v1-stable` + вернуть difficulty.var из backup-v1-stable.
