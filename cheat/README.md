# Чит-пак для теста новой версии

Оверлей данных. Начинаешь НОВУЮ партию на сложности «Начинающий».
Откат к чистому релизу: `git reset --hard release-v1-stable` (или скопировать
var-файлы из `.grechman/backup-v1-stable/` обратно).

## Что даёт
- Старт: 1 000 000 золота, 100 000 кристаллов.
- Ополченец даёт 400 000 опыта. Каждый тайник стерегут 2 ополченца =
  800 000 опыта за бой, герой сразу 30 уровня.
- Все постройки по 1 золоту, без ресурсов (гейты найма - Капитолий,
  Кристальные столпы, Великая пирамида, Великий алтарь - строишь за пару ходов).
- **Тайник существ** - появляется в провинциях с 1 уровня на любом ландшафте.
  Стерегут 2 ополченца. При победе со 100% шансом падают ВСЕ 6 свитков найма
  (Игла смерти, Вечное царство, Оракул, Умертвие, Прародитель, Крысс) в сокровищницу.
- **Тайник заклинаний** - тоже с 1 уровня, стерегут 2 ополченца. При победе
  даёт свитки заклинаний. В пуле выпадения оставлены ТОЛЬКО 7 новых заклинаний
  (Ледяная змея, Шаровая молния, Раскалённая почва, Солнечный взрыв, Ледяной
  шторм, Гимн Проклятых, Подчинение), так что падают только они.
  За один тайник даёт несколько свитков; тайников на карте несколько - добьёшь
  остаток на соседних.

## Включить
Скопировать `cheat/var/*.var` в `var/` игры с заменой.

## Выключить
`git reset --hard release-v1-stable` - вернёт чистый релиз без читов.
(difficulty.var не в гите: восстановить из `.grechman/backup-v1-stable/var/`.)
