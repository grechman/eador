# Eador NH 25.0101 - мод-релиз v1

5 лидеров (Лич, Оракул стихий, Умертвие, Прародитель, Повелитель небес) + Великий Крысс,
свитки найма, Небесный шпиль, ребаланс стихийной магии Оракула.

## Установка
Скопировать `var/`, `Text/`, `dat/` поверх установленной игры (NH 25.0101) с заменой.
Остальные файлы игры не менялись. Старые сейвы - на свой страх, лучше новая партия.

ВАЖНО: в `Eador.cfg` игры поставить `Max illustration (default 259, max 300): 260`
- иначе не подтянется картинка диалога Небесного шпиля (у неё id 259).
